### Краткое описание:
Это домашняя работа №2 содержащее классы позволяющее удобнее работать с ингредиентами и списками продуктов.

### Установка и запуск:
Для установки напишите следующие команды:
```bash
git clone https://github.com/ubmt2/HW2_SE.git
cd HW2_SE
pip install -r requirements.txt
```

### Запуск тестов:
Для запуска тестов, перейдите в корневую папку проекта и напишите команду:
```bash
pytest
```
